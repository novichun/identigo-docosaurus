Az **identiGO API** lehetővé teszi, hogy az Ön vállalatának már meglévő rendszere automatikusan szinkronizáljon az identiGO-val egyszeri leprogramozott összekötés után. 
Gyakori eset a következő: 
*Új ügyfelet visz fel  könyvelőszoftverébe, az azonnal bekerül az identiGO rendszerébe is, így a Pmt-s kötelezettségek kezelése egyszerűbbé válik.*

Az API gyorsítja az adatkezelést, csökkenti a manuális munka mennyiségét, és biztosítja az adatok naprakészségét. Ezen integrációhoz fejlesztő szükséges, de a folyamat az identiGO részletes dokumentációjával egyszerűen elvégezhető, minden felhasználó számára ingyenesen elérhető.

Ha szeretne bővebben olvasni az API jelentéséről, céljáról és működéséről, látogassa meg alábbi [cikkünket](https://forum.identigo.hu/t/mi-az-api-es-miert-fontos/).
