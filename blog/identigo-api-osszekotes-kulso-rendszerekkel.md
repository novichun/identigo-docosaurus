# Mi az API és miért fontos?

Az identiGO programozottan összeköthető más, akár **webes** akár **telepített, vastag kliens** alkalmazásokkal. Szabványos felületeket használunk, amikre a szoftverfejlesztők bármikor, **tőlünk függetlenül** is, rá tudnak fejleszteni.

Az API lehetővé teszi a fejlesztők számára, hogy különböző platformokon és eszközökön működő alkalmazásokat hozzanak létre anélkül, hogy teljesen újra kellene írniuk az alkalmazást. Ezáltal bővíthető a funkcionalitás és csökkenthető a fejlesztési idő és költség.

Az identiGO API használata minden előfizető számára INGYENES.

Néhány példa:

> * Ügyfelei már fel vannak töltve a könyvelőszoftverbe. Ezt egy összekötés után automatikusan szinkronban lehet tartani az identiGO-val. Tehát, ha felveszünk egy ügyfelet a Windows-os telepített könyvelőprogramban, az automatikusan megjelenik az identiGO-ban is.

> * Saját ingatlan-nyilvántartó rendszerben kezeli a folyamatokat és a jelenlegi ügyfeleket. Az összekötést követően a szerződés lezárását elegendő az ingatlan-nyilvántartó rendszerben adminisztrálni, mert az identiGO is leköveti a szerződés állapotát.

> * Tömeges műveletek: lehetőség van egyedi igények szerinti excel script-et írni. Így egy Excelbe felsorolva az adatokat azok megjelennek identiGO oldalán is és fordítva.

> * Ügyfél kiszolgálása közben elegendő a belső vállalatirányítási rendszert *kattintgatni*. Az ügyfél rögzítése után az egy szinte teljesen kitöltött átvilágítási adatlap nyílik meg közvetlenül az identiGO-ból, amit egyből lehet nyomtatni.

Az API segítségével fejlesztők harmadik féltől származó funkciókat és szolgáltatásokat adhatnak hozzá az alkalmazásaikhoz.
